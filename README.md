# Cine Família ADCG

Sistema de reserva de lugares para a sessão exclusiva de **A Virada: Ignição da Alma** no UCI Park Shopping Campo Grande (23/11/2026, 19:30).

- Site: https://12a7a3lrl-creator.github.io/cine-familia/
- Código do site: pasta `docs/`
- Configuração do Firebase e do evento: `docs/config.js`
- Regras de segurança do banco: `firestore.rules` (colar no Console do Firebase)

Sem `config.js` preenchido, o site roda em modo demonstração (dados só no navegador).
